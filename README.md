# فندق ومطعم البتراء — نظام الحجز وإدارة الفندق

نظام كامل بالعربية لفندق البتراء (البحصة، شارع الاتحاد، دمشق):

- **موقع الحجز للضيوف** (`/`): توفر وأسعار مباشرة لكل ليلة، حجز خلال دقيقة، تذكرة حجز برقم AP-XXXXX، متابعة الحجز وإلغاؤه من صفحة «حجزي».
- **لوحة الاستقبال والإدارة** (`/admin`): لوحة اليوم، لوحة الغرف (75 غرفة)، مخطط الحجوزات بالسحب والإفلات، الحجوزات، تسجيل ضيف مباشر، الدخول والخروج، حساب الضيف والفاتورة والدفعات بالدولار والليرة، الضيوف، التدبير الفندقي، التقارير، الأسعار والمواسم، الإعدادات، المستخدمون والصلاحيات، سجل النشاط.
- **تنبيه فوري**: كل حجز من الموقع يظهر فوراً في لوحة الاستقبال مع صوت، ويُرسل تلقائياً كرسالة واتساب إلى أرقام الاستقبال (عبر CallMeBot المجانية)، ويستطيع الضيف أيضاً إرسال تفاصيل حجزه إلى واتساب الاستقبال بضغطة.

لا يحتاج أي مكتبات خارجية. يكفي Node.js 18 أو أحدث.

## التشغيل

```bash
node server.js
# الموقع:      http://localhost:3000/
# الاستقبال:   http://localhost:3000/admin
```

عند أول تشغيل يُطبع حساب المدير (`admin`) وكلمة مرور مؤقتة، وتُحفظ أيضاً في `data/FIRST-LOGIN.txt`. سيطلب النظام تغييرها عند أول دخول، ثم يعرض إعداداً سريعاً لرقم واتساب الاستقبال.

للتجربة ببيانات أمثلة: `npm run demo` (تُحفظ في مجلد منفصل `data-demo`).

## قبل التشغيل للضيوف

1. من «الغرف والأسعار»: راجع أسعار الأنواع الستة وعدد الغرف وأنواعها، وارفع صور الفندق الحقيقية لكل نوع.
2. من «الإعدادات»: رقم واتساب الاستقبال، أرقام التنبيه التلقائي مع مفتاح CallMeBot، سعر صرف الليرة، أوقات الدخول والمغادرة.
3. من «المستخدمون»: أضف حسابات موظفي الاستقبال والتدبير الفندقي.

### تفعيل رسائل واتساب التلقائية (CallMeBot)
من هاتف كل موظف يريد التنبيه: أضف رقم CallMeBot إلى جهات الاتصال (موجود في https://www.callmebot.com/blog/free-api-whatsapp-messages/) وأرسل له:
`I allow callmebot to send me messages`
سيرد بمفتاح apikey. أدخل الرقم والمفتاح في الإعدادات، ثم «إرسال رسالة تجريبية».

## الاستضافة المجانية (Render + Supabase)
1. Supabase: مشروع جديد ← SQL Editor ← نفّذ محتوى `supabase.sql`. من Project Settings ← API انسخ Project URL والمفتاح السري (secret / service_role).
2. GitHub: ارفع محتوى المجلد إلى مستودع خاص.
3. Render: New ← Web Service ← اختر المستودع ← Language: Docker ← Instance: Free، وأضف المتغيرات:
   `SUPABASE_URL` ، `SUPABASE_KEY` ، `ADMIN_PASSWORD` (كلمة مرور أول دخول) ، `COOKIE_SECURE=1`
4. UptimeRobot (مجاني): راقب `https://YOUR-APP.onrender.com/api/ping` كل 5 دقائق حتى لا ينام الموقع.

## النشر على خادم خاص
- أي خادم VPS: `PORT=80 node server.js` أو خلف Nginx مع HTTPS، ويفضّل تشغيله عبر `pm2` أو `systemd`.
- Docker: `docker build -t alpatra . && docker run -d -p 3000:3000 -v alpatra-data:/app/data alpatra`
- مع HTTPS اضبط `COOKIE_SECURE=1`.
- البيانات في `data/alpatra.json`، مع نسخة احتياطية يومية مضغوطة في `data/backups` (آخر 30 يوماً). يمكن أيضاً التنزيل والاستعادة من الإعدادات.

## البنية
```
server.js          خادم HTTP بدون مكتبات + حفظ البيانات + تنبيهات واتساب
public/engine.js   منطق الفندق كاملاً (التوفر، الأسعار، الحجوزات، الحسابات، الصلاحيات)
public/api.js      طبقة الاتصال (تعمل مع الخادم، أو محلياً في وضع المعاينة)
public/index.html  موقع الضيوف
public/admin.html  لوحة الاستقبال والإدارة (+ admin.js)
public/media/      الصور والفيديو (Unsplash و Mixkit — مجانية للاستخدام التجاري)
```

الأدوار: **مدير** (كل شيء) · **استقبال** (الحجوزات والضيوف والفواتير والتقارير) · **تدبير فندقي** (حالة الغرف فقط).
